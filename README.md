# SSITS IT Fest 2026 — BYTEPULSE '26 ⚡

Annual Inter-Collegiate IT Symposium for **Sir Syed Institute for Technical Studies (SSITS)**.

## 🚀 Features
- **Cyberpunk / Synthwave Visual Design**: Atmospheric midnight palette (`#0B001A`, `#00F0FF`, `#FF007F`), living animated mesh gradients, and subtle tech grid textures.
- **Apple-Style Flying Logo Transition**: Centered college emblem trace glides with optical motion blur and docks directly into the floating navbar on scroll.
- **Floating Glassmorphic Navbar**: Dual-layer edge reflection, responsive mobile slide-in drawer from the left with dedicated close button and outside tap dismissal.
- **Mobile-First & App-Locked**: Multi-touch pinch-to-zoom and double-tap zoom suppression to preserve native web-app immersion.
- **Zero-Build Stack**: Pure HTML5, CSS3, and modern Vanilla JavaScript — zero terminal or bundle build steps required.

## 🛠️ Stack
- **HTML5 & Modern CSS**
- **Vanilla JavaScript** (Hardware-accelerated compositor transitions)
- **Google Fonts** (Space Grotesk & Outfit)
